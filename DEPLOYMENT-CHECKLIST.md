# Launch checklist

- [ ] Run `npm install` and `npm run build`.
- [ ] Confirm both routes load: `/corporate/` and `/creator/`.
- [ ] Check Chrome on Android and Safari on iPhone if available.
- [ ] Test keyboard focus, reduced motion and tap interactions.
- [ ] Create/configure the Formspree endpoint and test form submission.
- [ ] Confirm the person represented has approved the bio, photos and public launch.
- [ ] Add chosen Reel URLs if individual videos should be featured.
- [ ] Deploy on free hosting and test the live URL before sharing.
